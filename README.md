# My Website

A simple HTML, CSS, and JavaScript website. Nothing to install.

- `index.html`: the home page
- `about.html`, `resume.html`, `portfolio.html`, `contact.html`: one page per menu item (each has its own copy of the menu and footer)
- `styles.css`: colors, fonts, and layout (change the colors at the top)
- `script.js`: the mobile menu and footer year
- `images/`: put pictures here

To see it, double-click `index.html` to open it in your browser.
